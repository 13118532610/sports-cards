# 画面：量出来的参数

下面每个数都是从参考片（1080×1440、22 秒、6 张卡）里逐帧量的，不是估的。改可以，先知道原来是多少。

## 画布

| 项 | 值 | 说明 |
|---|---|---|
| 尺寸 | 1080×1440（3:4） | 小红书/视频号竖版通用；抖音可另出 1080×1920，网格跟着重排 |
| 底色 | `#292929` | 实测 (41,41,41)。不是纯黑，纯黑会把抠像的暗部吃掉 |
| 网格线 | `#3a3a3a`，2px | 和底色差 17 级，够了。再深会脏，再浅看不见 |
| 网格间距 | 196px | 实测竖线在 67、263、459…，从 67 起算 |
| 暗角 | 径向，42% 处起压到 42% 黑 | 让中间的主体立住；压太狠会显脏 |

## 字

| 项 | 值 |
|---|---|
| 标题字体 | 重黑体（阿里妈妈数黑体 / 思源黑体 Heavy / 苹方 Heavy）；**不要用细体**，描边会吃掉字 |
| 标题字号 | 78px（最长一行超过 13 字就自动缩，缩到 48 为止） |
| 标题行高 | 1.08，最多两行，居中 |
| 标题位置 | top 120，左右各留 90 |
| 标题颜色 | `#F5C400`（实测参考片 (242,200,11)，偏橙一点用 `#F2C80B`） |
| 标题描边 | 7px `#131313`，`paint-order: stroke fill`（先画描边再填字，不然字会被描边吃瘦） |
| 标题投影 | `0 9px 0 #131313, 0 14px 22px rgba(0,0,0,.6)` —— 硬投影是这套风格的招牌，不能省 |
| 说明行字号 | 54px，白色，描边 5px `#131313`，最多一行 17 字 |
| 说明行位置 | bottom 96，左右各留 70 |
| 角标 | 26px，`#cfcfcf`，bottom 36，**一帧最多一行** |

## 主体

| 项 | 值 |
|---|---|
| 安全带 | top 330 → bottom 220（中间这一段给图，标题和说明各有自己的地方） |
| 抠像 | 按高度定（默认 980，全身人 1080–1100），宽度跟着走，`drop-shadow(0 26px 34px rgba(0,0,0,.55))` |
| 照片卡 | 等比缩，**不裁画面**；圆角 10px；`0 28px 60px rgba(0,0,0,.62)` + 1px 白色 6% 的内描边 |
| 主体宽度上限 | 1000px（左右各留 40，别顶边） |

## 一笔账：一屏能放多少字

标题 13 字 × 2 行 + 说明 17 字 = 最多 43 字。
超过就不是一张卡了，拆成两张。参考片平均每卡 20 字上下。

## 排版手感

- **标题两行要断得对**：断在语义处（"扬眉吐气！C罗进球后模仿 / 边裁举旗嘲讽"），不要断成"模仿边 / 裁举旗"。
  在 `cards.json` 里直接用 `\n` 指定断行，不要靠自动折行。
- **说明行不重复标题**：标题说"两次进球都被吹了越位"，说明就不要再写"越位"两字，写"两次都白庆祝"。
- **主体要顶天不顶边**：抠像的头顶离标题留 30–60px，脚下可以一直延伸到说明行上面。
- **照片卡和图卡不要连着放三张**：连着三张照片卡，节奏就平了；中间插一张纯字卡，眼睛才歇一下。

## 复用

`starter/card.css` 里的 `:root` 就是这张表。换风格只改这几个变量，不要逐条改样式。

```css
:root{
  --bg:#292929; --grid:#3a3a3a; --grid-step:196px;
  --gold:#F5C400; --ink:#131313;
  --title-size:78px; --cap-size:54px;
}
```


## 运动：每张卡不一样，才不像模板

同一个动作重复七次，观众第三张就腻。`motion` 字段选动作，没写就按位置轮换。

| motion | 怎么动 | 适合 |
|---|---|---|
| `punch` | 前 1/3 冲到 1.16 倍再缓回 1.10，同时上移 22px | 钩子、要"砸"出来的数字 |
| `push` | 匀速推到 1.12 倍、上移 18px | 常规展示 |
| `pull` | 从 1.12 拉回 1.02（看整体） | 结论、收尾 |
| `panL` / `panR` | 放大 1.16 后横向移 42px | 照片卡（放大必须盖过位移，否则露边） |
| `float` | 4% 呼吸 + 8px 上下浮 | 抠像人物 |

背景网格：整体从 1.02 放大到 1.22，同时位移 26–46px —— **要看得见**，几个像素的抖等于没动。
再加一层扫光（`#card .sweep`）：一道柔光从左边扫到右边，纯字卡全靠它撑住"在动"。

标题入场（`titleStyle`）：`rise`（上浮）/ `pop`（弹一下）/ `blur`（从虚到实）。
**只有第一张做入场**，后面的卡在转场里滑进来，再淡入会变成"黑底滑进来"。

自检：同一张卡首尾两帧的像素差要 > 3。低于这个数，观众看不出在动。
