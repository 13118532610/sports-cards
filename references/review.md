# 交付前自检

按顺序过，哪一条不过就回去改，不要"先交了再说"。

## 文字

- [ ] 6 条标题连起来念，是一个完整的故事，不是一份摘要。
- [ ] 每张卡只讲一件事；删掉任意一张，故事就不完整（否则删掉它）。
- [ ] 标题里有具体动作（举旗、推射、摊手），不是形容词（精彩、震撼）。
- [ ] 说明行没有重复标题说的话。
- [ ] 断行是手动指定的，断在语义处，两行长度差不超过 3 个字。
- [ ] 没有一张卡的标题超过 13 字/行（超了字号会被缩到难看）。

## 图

- [ ] 每张卡的主体在缩略图尺寸下也能认出是谁。
- [ ] 抠像边缘逐张看过：头发、手臂缝隙、浅色球衣。
- [ ] 没有连续三张都是照片卡（节奏会平）。
- [ ] 没有一张图的标题和图对不上。
- [ ] 比分牌、台标、字幕条：要么是证据（留着），要么框掉/换帧，不要半截露在边上。
- [ ] 照片卡没有被裁掉半个头（`photo` 是等比缩放，不裁画面）。

## 出图

- [ ] `cards.mjs` 跑完没有页面报错（尤其字体 404）。
- [ ] 1080×1440 原尺寸看过至少 3 张，不是只看缩略图。
- [ ] 描边没有把字吃瘦（`paint-order: stroke fill` 生效）。
- [ ] 网格在暗部仍然看得见（太淡就像没底纹）。

## 声音 / 成片

- [ ] `ffprobe` 打得开，时长和 `timeline.json` 对得上。
- [ ] 响度 −14 LUFS 上下。
- [ ] 每张卡一帧抽出来看过，没有黑帧、没有卡到一半。
- [ ] 最后一张卡留够了（说完话还有 0.8 秒以上）。
- [ ] 加底乐的话，人声每句都清楚。

## 交付说明里必须写

- 出了几张，每张说什么。
- 哪些图是你没把握的（糊、版权、抠得毛）。
- 哪些是临时配音（还没换正式声音）。
- 素材来源（比赛名称、转播方、官方渠道），方便发的时候写简介。
