# 踩过的坑

真做出来的坑，按发生顺序记。每条都写"怎么发现的、怎么解决"，下次遇到直接跳到解决。

## 图

**1. 从视频取帧，取到转场那一帧（糊的）**
想取"庆祝"的瞬间，按 8.6 秒取，结果是两张卡之间的推拉转场——整帧运动模糊。
解决：先用 `frames.py --sheet 3` 出联系表，看哪一格是**稳定的整卡**再取；取完立刻看一眼，糊了就换前一秒。

**2. 抠像把转播比分牌一起抠进来了**
抠一名球员，画面右下角有 "5:3 FULL-TIME" 图形，rembg 把它当主体留了下来。
解决优先级：**换一帧**（最好） → `cutout.py --drop x0,y0,x1,y1` 框掉 → 接受它（如果比分牌本来就是证据，就别抠人，改用照片卡）。

**3. 抠完是糊的，但原图很清晰**
大概率是取帧取到了转场，或者 `--max-h` 设得太小把图缩小了又放大。
解决：看 `cutout.py` 打印的原图尺寸和主体占比；占比 < 8% 说明人在画面里太小，抠出来一定糊，换图。

**4. 浅色球衣 + 亮背景，边缘一圈毛**
黄色球衣贴着黄色看台，rembg 分不开。
解决：换一张背景对比明显的帧；或者干脆用照片卡，不抠。

**5. 照片卡被裁掉了半个头**
早期用 `object-fit: cover` + 固定高宽，图会被裁。
解决：照片卡**等比缩**（`width:auto; height:auto; max-height:100%`），要裁就自己裁好再放进去。

## 字

**6. 标题自动折行，断在奇怪的地方**
"…模仿边 / 裁举旗嘲讽" 这种断法，一眼就出戏。
解决：`cards.json` 里直接写 `\n` 指定断行，永不放任自动折行。

**7. 标题溢出到第三行**
12 个字按 78px 排是 936px，容器只有 900px，于是折行。
解决：`card.js` 的 `fit()` 按"最宽一行 × 字号 ≤ 容器宽"算，超过就缩；缩到 48 以下就改写文案。

**8. 描边把字吃瘦了**
`-webkit-text-stroke` 默认描边压在字形上，细体会被吃掉一半。
解决：`paint-order: stroke fill;`（先描边后填色）。重黑体也要加，不然小字会糊。

**9. 说明行和标题重复**
标题"两次进球都被吹了越位"，说明又写"两次进球都越位"。
解决：说明行只写三种——补细节、换视角、给判断。

## 排版

**10. 一格网格对不上另一格**
网格用 `repeating-linear-gradient` 从 0 开始，参考片是从 67px 开始。
解决：`background-position: 67px 67px`，步长 196px。

**11. 主体压到说明行**
抠像按高度 1000 排下去，脚踩到说明行上。
解决：主体限制在安全带里（top 330 / bottom 220），`max-height:100%`。

**12. 缩略图看着好好的，原尺寸一看全是问题**
描边糊、字压图、边缘毛，缩略图都看不出来。
解决：交付前至少 3 张按 1080×1440 原尺寸看。

## 流程

**13. 图卡数量和文案句数对不上**
`cards.json` 6 张，`script.json` 5 句，合成时第 6 张卡只有画面没声音。
解决：`video.mjs` 会直接报错（卡数 < 句数）。拆卡时就把两边序号对齐，`id` 用同一套（c01…）。

**14. 换配音后时间轴错位**
配音换了，时长变了，但卡还是按老时长排。
解决：`voice.py` 每次重跑都会重写 `timeline.json`；`video.mjs` 只认 `timeline.json`，不要手写时长。

**15. 网络不稳，图源时通时不通**
同一台机器，昨天能打开的图片站今天超时；搜索引擎接口基本都被反爬挡住。
解决：**不要把爬虫写进交付流程**。默认用"用户给图 / 官方图 / 视频取帧"，把搜索当兜底，拿不到就停下来要图。

## 环境

**16. rembg 模型路径**
`rembg` 新版把模型放 `~/.u2net/`，而一些旧脚本读 `~/.rembg/models/`。
解决：`python3 -c "from rembg import new_session; new_session('isnet-general-use')"` 跑一次，看模型落在哪，按实际位置引用。

**17. Playwright 的 macOS 版本限制**
新版 Playwright 在某些旧 macOS 上不发布 Chromium（`Playwright does not support chromium on mac13-arm64`）。
解决：把 playwright 钉到有对应构建的版本，或手动把 Chrome for Testing 放进 `~/Library/Caches/ms-playwright/`。

**18. 字体 404，页面一直转圈**
`card.css` 里写了 `fonts/xxx.ttf`，但目录里没有这个文件，页面等字体等到超时。
解决：字体放进片子的 `fonts/`，或者把对应的 `@font-face` 删掉用系统黑体；出图前看 `cards.mjs` 有没有报 404。
