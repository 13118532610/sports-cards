# 配图：从哪来、怎么挑、怎么抠

图是这套东西的命门。**一张糊图能把 5 张好卡毁掉。**

## 图的四个来源（按优先级）

| 顺序 | 来源 | 优点 | 坑 |
|---|---|---|---|
| 1 | **用户给的图** | 一定拿得到，清晰度可控 | 要用户先准备 |
| 2 | **官方渠道**：俱乐部/联赛官网、官微、官方海报 | 清晰、权威、版权风险低 | 官方图多为宣传照，缺少比赛动作 |
| 3 | **视频取帧**：比赛回放、官方集锦 | 动作最全，能取到任何一秒 | 需要视频源；转播画面带比分牌/台标 |
| 4 | **搜索引擎** | 想要什么有什么 | 反爬、图质参差、版权风险最高 |

**默认走 1 → 2 → 3。** 4 只在前面都拿不到时兜底，并且要自己看一眼图质。

> 网络现实：这台机器上 Bing / 百度 / 搜狗的图片接口都被反爬挡住，脚本里**不内置图片爬虫**。
> 需要联网找图时，用浏览器手动搜、存到 `assets/src/`，再走后面的流程。
> 有稳定图源的话，可以自己写一个下载脚本接进来——`cutout.py` 和 `cards.mjs` 只认文件路径。

## 从视频取帧

```bash
# 指定秒数取帧
python scripts/frames.py 比赛.mp4 --at 12.4,88.2,101.6 --out assets/src/

# 先看全局：每 20 秒一格的联系表，挑出要哪几段
python scripts/frames.py 比赛.mp4 --sheet 20
```

挑帧的标准，按重要程度排：

1. **动作完整**：手举起来了、人转过来了。半截动作最难看。
2. **不糊**：运动模糊的帧直接丢，别想着"修一下"。
3. **背景干净**：抠像最怕背景和主体同色（黄球衣 + 黄看台）。
4. **没有转播图形**：比分牌、慢放图标、台标、字幕条。有就换一帧。

## 抠像

```bash
python scripts/cutout.py assets/src/c罗.png assets/cut/c罗.png
python scripts/cutout.py assets/src/举旗.png assets/cut/举旗.png --drop 420,860,760,1010
```

`cutout.py` 会做四件事：rembg 抠主体、丢掉小于最大块 2% 的碎块、裁到主体、限高。

**抠完必须要看边缘**：

- 头发：和背景同色时会被吃掉一圈，换一张。
- 手臂和身体之间的空隙：会留一块背景，用 `--drop` 框掉，或者干脆换动作。
- 浅色球衣（白、黄）贴着亮背景：边缘会毛，宁可换帧。
- **转播比分牌**：rembg 会把那块当主体留下来。做法优先级：换一帧 > `--drop` 框掉 > 接受它（比分牌本身可能是证据，那就别抠，用照片卡）。

## 照片卡 vs 抠像：怎么选

| 用照片卡 | 用抠像 |
|---|---|
| 比分牌、官方海报、颁奖台、全景 | 单个动作：举旗、摊手、怒吼、庆祝 |
| 图本身有信息（比分、队徽、文字） | 图的信息就是"这个人在干什么" |
| 抠了会假（人群、球场） | 抠了更干净（背景乱、有杂物） |

**一张卡只用一种。** 又想抠人又想留比分牌，就拆成两张卡。

## 版权

这类图几乎一定涉及他人版权。做评论、解读、资讯，风险相对低；直接搬运原图当自己的，风险高。

- 只用**必要的那一张**，不整段搬运。
- 视频/图文发布时**在简介写清来源**（比赛名称、转播方、官方渠道）。
- 不拿真实球员、俱乐部名字给自己起名。
- 商用（带货、广告）要单独确认授权，这套 skill 不解决授权问题。

- 有没有三张连着都是照片卡、看起来一样？
- 有没有哪张的图和标题根本对不上？
